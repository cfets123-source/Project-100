# Whole-share overnight pullback v1: frozen research plan

[Alpaca's order table](https://docs.alpaca.markets/us/docs/orders-at-alpaca) permits a GTC stop for whole-share U.S. stock orders, while fractional stops are DAY-only. This variant tests whether the existing overnight daily pullback can be executed with whole shares in a $100 cash account. It is a new strategy version and cannot inherit the fractional worker's historical pass.

Use the fixed 79-symbol expanded equity/ETF universe and adjusted Alpaca IEX daily bars. With one position at a time, select the deepest 1.5% pullback below the five-day high while remaining above the 50-day average, using only the completed day. At the next session open, try candidates in rank order and buy the largest *integer* quantity allowed by available cash, 65% maximum account exposure, and a 2% account risk budget divided by a 3% stop. If none is affordable, skip. Set a 3% GTC stop and a 6% target. Evaluate stop-first when a daily bar crosses both and penalize a gap through the stop using the worse opening price. Charge 0.1% round-trip on position notional and test 0.2% sensitivity. Once a position exits, wait until the following session to make another decision. No shorting or leverage. Initial cash is $100; returns include idle cash and daily marks on open positions.

Freeze this rule and evaluator before inspecting its result. Use 2023–2024 for development and 2025–September 2026 for a separate recent confirmation. These daily bars were already inspected for the earlier overnight variant, so the later window is not pristine untouched data; positive results would still need forward paper fills, exact GTC-stop lifecycle, and fresh validation before live capital. The recent confirmation gate is at least 20 completed trades, positive account return after 0.1% cost, maximum drawdown no worse than 20%, and nonnegative return at 0.2% cost. Report both years separately, how often signals were unaffordable, and open-position censoring at sample end.
