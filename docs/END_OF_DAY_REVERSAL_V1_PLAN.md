# End-of-day reversal v1: frozen test plan

The [end-of-day reversal study](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5039009) reports price pressure on intraday losers near the close. It motivates a test; it does not establish that the exact rule below is profitable or executable by this app.

Use the existing fixed 20-symbol liquid U.S. stock/ETF universe and adjusted Alpaca IEX five-minute bars. The completed 15:20 Eastern bar determines the signal. Compare each symbol's return from its 9:30 open to its 15:20 close against SPY's return over the same interval. A candidate must be down at least 1% and underperform SPY by at least 1%. Exclude SPY itself. Select the two deepest relative losers, breaking ties by symbol. Enter at the 15:30 bar open, allocating at most 40% of account equity to each with no leverage. Apply a 0.75% stop and 1.5% target, with adverse stop priority when both thresholds occur in a bar and gap-through-stop penalties. Exit any survivor at the 15:55 bar open. Require every named bar; exclude an incomplete symbol-day rather than fill prices from a different time. Model 0.1% round-trip cost on each position; also report 0.2% cost sensitivity. Never carry overnight.

Freeze this code and plan before accessing January 2023–December 2024 five-minute data. Use 2025–June 2026 as an exploratory development diagnostic, because that period has been inspected for other candidates. Treat 2023–2024 as a fixed separate confirmation, not as a parameter search. The confirmation gate requires at least 50 completed trades, positive compounded account return after 0.1% cost, maximum drawdown no worse than 15%, and nonnegative return at 0.2% cost. Report each year, the missing required-bar count, and exit reasons. A pass is only eligibility to build an exact-version paper worker and collect a broker lifecycle; it does not enable live capital.
